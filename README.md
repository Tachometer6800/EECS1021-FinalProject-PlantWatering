My final project for EECS 1021

Usage Instructions

In "PlantsnWhatnot.JAVA":
Change "PORT" to port of your Arduino
Change "FOLDER_PATH" to desired folder path for CSV files
Change "timerLength" to how often you want the sensor to check

In "PlantsLogic":
Change "dryThreshold" to the percent dry you want your plant to be 
Change "cooldownConstant" to how many run cycles you want the water to saturate

Parts used:
Arduino UNO board
OLED Display (SSD1315)
Button
LED Socket Kit
Capacitive Moisture Sensor
MOSFET
Liquid Pump
